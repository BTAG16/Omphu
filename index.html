Git Journey

Your First Steps with Git

Git is how developers track changes, collaborate, and never lose their work. Here's where your journey begins.

🔧
Step 1

Install Git

Download and install Git on your computer. It's free and works on Mac, Windows, and Linux.

# Check if git is installed
git --version
👤
Step 2

Set Up Your Identity

Tell Git who you are. Every commit you make will carry your name and email.

git config --global user.name "Omphulusa"
git config --global user.email "omphu@email.com"
📁
Step 3

Create a Repository

A repository (repo) is where your project lives. Think of it as a smart folder that remembers everything.

# Create a new folder and start tracking it
mkdir my-first-project
cd my-first-project
git init
📸
Step 4

Make Your First Commit

A commit is like saving a snapshot of your work. You can always go back to any snapshot.

# Stage your changes
git add .
# Save the snapshot with a message
git commit -m "My first commit 🎉"
🌐
Step 5

Push to GitHub

Share your work with the world! GitHub is a platform to store and collaborate on your repos online.

# Connect to GitHub and push
git remote add origin <your-repo-url>
git push -u origin main

🔀
